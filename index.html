What is Claude to RIPCO?

A SEEM tool. And your digital assistant.

Claude is a large language model from Anthropic. At RIPCO we use it two ways: as a SEEM tool (Search, Extract, Explain, Model) for research and analysis, and as a digital assistant that can operate our tools on your behalf.

The same Claude powers both. What changes is the interface — Chat is a research tab, Cowork is an agent with hands on your files and Monday.com. The Skills Library below is Claude's playbook: skills tell it exactly how to route a request to the right board, the right column, and the right subitem.

The short version: Chat answers questions. Cowork does the work — including uploading files directly into Monday.com.

Chat

Read-only

The classic Claude conversation. Great for questions, drafting, thinking through problems, and one-off research.

  • Ask questions, get answers
  • Draft emails, summaries, memos
  • Web search for market intel
  • Cannot upload files to Monday.com
  • Cannot read your local computer
  • No skills, no plugins

Cowork

Full agent

Claude with hands. Point it at a folder and it works alongside you — reading files, running scripts, calling Monday, generating branded docs.

  • Everything Chat does, plus:
  • Uploads files directly into Monday.com boards
  • Reads leases, spreadsheets, PDFs from your desktop
  • Generates DOCX / HTML / PDF deliverables
  • Runs the full RIPCO plugin & skill library
  • Talks to Monday and any connector you've authorized
↑
Cowork uploads to Monday.com. Drop a Property Shark export into Cowork and it lands as enriched sales-comp items — no copy-paste, no manual column mapping.
Claude & Monday.com

Monday is where the work lives. Claude is how it gets done.

Every RIPCO deal, listing, lead, tenant, and marketing project lives on a Monday.com board. Claude — via Cowork and our plugins — is the operator that reads and writes those boards without you leaving the conversation.

Claude reads Monday first

Before writing anything, our skills fetch the exact board schema, column IDs, and existing linked records. This is why the agent never guesses a column name or duplicates a property.

Claude writes to Monday with rules

Each skill enforces RIPCO's write conventions — parent items vs subitems, signage dual-writes, contact-relation preservation, and duplicate detection scoped to the right board.

Claude generates from Monday

Status reports, tour books, BOV decks, and streetscapes pull live data from Monday. Update the board, regenerate the deliverable — no more stale exports.
